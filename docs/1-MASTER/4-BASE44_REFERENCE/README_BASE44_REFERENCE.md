## Rôle du dossier

Ce dossier conserve une version exploitable du prototype Base44 pour comparaison métier, visuelle et fonctionnelle.

Base44 est une référence de prototype. Ce dossier ne constitue pas une source technique finale et ne doit pas être copié directement dans le code officiel.

## Règles d’utilisation

- Utiliser Base44 pour comprendre les parcours, écrans, composants, entités et arbitrages visuels du prototype.
- Comparer Base44 avec le repo officiel avant toute reprise.
- Adapter les idées utiles dans le cadrage officiel avant codage.
- Ne jamais copier directement le code Base44 dans le repo officiel.
- Ne pas considérer Base44 comme preuve de conformité backend, sécurité, RBAC, RGPD ou architecture finale.
