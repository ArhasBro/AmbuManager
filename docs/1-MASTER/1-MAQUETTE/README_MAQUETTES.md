# README_MAQUETTES

## Rôle

Le dossier `MAQUETTE_PNG/` contient les anciennes maquettes PNG du projet.

## Statut actuel

Ces maquettes sont conservées comme base de comparaison et mémoire visuelle.  
Elles ont un statut transitoire / historique.

## Règle d'usage

Ces maquettes seront remplacées ou complétées après validation des nouvelles maquettes.  
Elles ne doivent pas primer sur les fiches fonctionnalités validées.
