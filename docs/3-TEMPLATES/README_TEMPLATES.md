# README_TEMPLATES.md

## Rôle du dossier
Le dossier `docs/3-TEMPLATES/` regroupe les templates de session utilisés pendant la reprise.

## Templates de session
- `TEMPLATE_SESSION.md` : ouverture de session Codex (production dans le repo).
- `TEMPLATE_CONTROLE_CHATGPT.md` : contrôle qualité ChatGPT des retours Codex (sans production repo).

## Templates complémentaires
- `TEMPLATE_DOD_SESSION.md`
- `TEMPLATE_RECAP_SESSION.md`
- `TEMPLATE_BLOC_SESSIONS_PROMPTS.md` : préparation des blocs, création des sessions et génération des prompts de lancement/contrôle.
